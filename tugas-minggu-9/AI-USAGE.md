1. AI Yang digunakan: ChatGPT 

2. Tujuan Penggunaan:
AI digunakan sebagai alat bantu belajar selama mengerjakan tugas
Pemrograman Web Minggu ke-9. Membantu fokuskan pada pemahaman dan
penerapan metode GET dan POST menggunakan PHP.

3. Bentuk Penggunaan AI
AI digunakan untuk membantu: 
- Menjelaskan fungsi dan perbedaan metode GET dan POST pada PHP. 
- Membantu membuat fitur pencarian sederhana menggunakan GET dan array berisi contoh barang.  
- Memahami validasi di sisi server untuk kolom wajib dan format email. 
- Memahami kode status HTTP 405 dan 422, serta 303 setelah data berhasil diproses. 
- Membantu menemukan kesalahan penulisan sintaks HTML pada elemen <textarea>.
- Membantu memberi penjelasan langkah pengujian input valid, kolom kosong, email tidak valid, input script, dan akses endpoint POST menggunakan GET. 
- Membantu memahami cara memeriksa request GET dan POST melalui panel Network pada browser serta melihat riwayat commit Git.

- Membuat dan mengedit file proyek 
- Memasukkan serta menyesuaikan kode 
- Menjalankan aplikasi secara lokal menggunakan XAMPP
- Melakukan pengujian melalui browser 
- Memeriksa hasil pengujian
- Menyiapkan bukti proses pengerjaan.
- Memperbaiki kesalahan pada penulisan script
